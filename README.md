# CosmoDash

SaaS de CRM com assistente de IA Cosmo. Hoje é um protótipo navegável de 16 telas, sem backend: 14 abas no menu, mais o perfil de cada colega e o de cada organização.

```bash
npm run dev
```

A demo abre em http://localhost:4173. As instruções do projeto estão em [CLAUDE.md](CLAUDE.md), e o processo, em [docs/fluxo-de-desenvolvimento.md](docs/fluxo-de-desenvolvimento.md).
